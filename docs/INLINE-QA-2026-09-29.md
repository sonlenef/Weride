# Inline requirement Q&A and system landscape parity

## Delivered behavior

- The matrix and the selected group on System landscape use one shared RequirementsTable.
- Click the requirement title, non-interactive row area or Q&A count to open its discussion; only one panel is open per list. Clicking the same trigger closes it. PIC buttons and detail/breakdown/assumption links do not accidentally toggle the panel.
- The inline panel shows original askers, created time where recorded, question text, context, recorded answer, status and version. The author is resolved from createdBy and the member directory, not updatedBy or free-text owner.
- Members can post a question inline, edit their own question using the multilingual editor and delete their own question with confirmation. Existing English canonical-content requirements are retained; stored VI/SV translations are supported.
- Initial discovery proposals are labeled as Madison drafts, not questions submitted by a particular employee.
- Unsaved composer text is held in component memory while switching rows/filtering or changing system groups. It is not uploaded, and is discarded on leaving the page/sign-out. A browser unload warning is registered for non-empty drafts.
- System landscape preserves all original group-to-requirement mappings and adds the same PIC, Q&A, status, discovery counts and detail links as the matrix. Group search, PIC filters, sorting and scoped CSV are also available.
- Expanded forms adapt to the actual content-column width, including mobile and narrower desktop windows.

## Ownership boundary

Firestore entry update/delete rules enforce createdBy == request.auth.uid for Q&A. The store checks the same rule against existing data and again inside the transaction; supplied payload kind/author cannot grant permission. Original author metadata and requirement/kind remain immutable.

Question ownership applies on matrix, system and full detail pages, including changes to recorded answers. Being PIC does not transfer ownership. Existing team editing of breakdowns, assumptions, vendor responses and assignments is unchanged. No general administrator bypass was added to the client.

No database migration, seed reset or production sample question was performed. Microsoft domain authentication, no-mailbox-verification login, the 24-hour session window, share-link rewrites and private source protection are preserved. AI Review Pack continues excluding structured member/author metadata.
