# Remember Microsoft sign-in for 24 hours

## Requested behavior
Remember an eligible Microsoft @madison.dev login on the same browser and origin,
including closing and reopening the browser, for up to 24 hours from sign-in.
Explicit sign-out clears the local Firebase session. Email verification remains unnecessary.

## Implementation
- Firebase local-first persistence, with migration from existing SESSION sessions.
- Deadline: signed Firebase auth_time + 86400 seconds; refresh and reload do not extend it.
- Client checks restoration, token changes, deadline timer, and focus/pageshow/visibility resume.
- Firestore member() enforces the deadline independently using request.time.
- Authenticated sharing API source uses the same policy; public snapshot lifetimes are independent.
- Same-origin sign-out signal also covers tabs that migrated from legacy SESSION persistence.
- Browser storage restrictions fall back to the SDK's available mode with a visible warning.
- No passwords, refresh tokens, or authentication payloads are logged by application code.
- Firebase retains credential ownership; no custom session cookie or bearer-token database is added.
- Source requirements, collaboration entries, PIC assignments and billing are not changed.

## Validation
61 unit tests passed, 47 Firestore rule/emulator tests passed, 29 Playwright tests passed,
and 18 sharing API tests passed: 155 tests total.
Browser regressions include actual Chromium process shutdown/restart with a synthetic,
network-isolated local session, migration, cross-tab sign-out, virtual 24-hour expiry,
and sleep/resume expiry checks. These are not real employee OAuth acceptance tests.

## Operational limits
The 24 hours is an absolute window, not inactivity/sliding expiry. Clearing site storage,
private browsing, or identity-provider/session revocation may require earlier sign-in.
Sign-out on this browser is not a global Microsoft sign-out or all-device token revocation.
